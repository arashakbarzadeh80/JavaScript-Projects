JavaScript Projects

This repository contains several small projects I created to practice and demonstrate my JavaScript skills. These projects use JavaScript to add functionality, user interaction, calculations, and dynamic content to web pages.

🍕 Pizza Menu

A simple interactive pizza ordering application. Users can select different pizza sizes and toppings, and JavaScript calculates the total price based on their selections. This project demonstrates the use of JavaScript functions, conditional statements, and DOM manipulation.

🧮 Calculator

A basic calculator that performs common mathematical operations such as addition, subtraction, multiplication, and division. This project provides practice with JavaScript functions, event handling, and working with user input.

❌⭕ Tic-Tac-Toe Game

An interactive two-player Tic-Tac-Toe game created with HTML, CSS, and JavaScript. Players take turns placing X and O on a game board, while JavaScript keeps track of the moves and determines when a player wins or the game ends in a draw. This project demonstrates JavaScript logic, arrays, event handling, and DOM manipulation.

These projects helped me develop practical experience with JavaScript and understand how JavaScript can be used to create interactive and dynamic web applications.
